# Elevate AI Future

Public, standalone website for the Elevate Innovation Technologies AI data-center blueprint.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Deploy on Vercel

Import `Blocpod/ElevateAI` in Vercel. Vercel will detect Next.js automatically. No authentication, private middleware, database, or environment variables are required.
